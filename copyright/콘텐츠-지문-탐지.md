## 1. 지문(canary) — 검색 유일 표현

각 글에서 **자연스러운 본문 문장**(strip 불가)이면서 다른 곳에 존재할 가능성이 거의 없는 표현.
복제본은 이 문장을 그대로 안고 가므로, 정기 검색으로 출처를 증명할 수 있다.

| # | 글 | 지문 문장 (큰따옴표째 정확검색) |
|---|---|---|
| 01 | 왜 우리는 영혼의 거울을 매일 보지 않는가 | `"비춤은 해석이 아닙니다"` · `"영혼의 거울 앞에 서려면 먼저 멈춰야 합니다"` |
| 02 | 리추얼은 왜 나를 실제 앞에 세우는가 | `"실제를 가리던 분주함을 잠깐 걷어내는 일"` · `"습관은 하루를 흘려보내고, 리추얼은 하루 앞에 잠깐 멈춰 세웁니다"` |
| 03 | 연약함은 왜 관계를 약하게 하지 않는가 | `"서로가 실제로 닿을 수 있는 작은 틈이 됩니다"` · `"두 사람이 각자 단단한 표면만 마주 댈 때"` |
| 04 | 한 문장 뒤의 삶 | `"그릇이 아니라 열쇠에 가깝습니다"` · `"내가 지나온 삶의 윤곽이 됩니다"` |
| 05 | 받은 것이 흘러갈 때 | `"빈 손으로 건넨 것은"` · `"의무로 준 것은 의무로 받아질 뿐입니다"` |
| 06 | 관계는 나를 넘어 어디까지 이어지는가 | `"가장 가까운 관계는 어쩌면 나 자신과의 관계입니다"` · `"올라가야 할 사다리가 아닙니다"` |
| 07 | 변화의 비밀 | `"변화는 갚아야 할 숙제가 아닙니다"` · `"애쓴 흔적도 없이 어느새 와 있곤 합니다"` |
| 08 | 사랑은 어떻게 연약함을 품고 앞으로 가게 하는가 | `"사랑은 약함을 지우지 않습니다"` · `"사랑의 세 방향은 사실 하나의 흐름입니다"` |
| 09 | 오늘이 선물이 되도록 | `"다 이해한 사람에게만 주어지는 보상이 아니라"` · `"이미 받아든 시간으로 다르게 보입니다"` |

> 지문 정본은 라이브 `app/journal/articles.ts`. 본문 수정 시 이 표가 함께 유효한지 확인.

## 2. 정기 탐지 (월 1회 권장)

1. **구글 정확검색**: 위 지문을 큰따옴표째 그대로 검색. onmoment.kr 외 도메인이 나오면 복제 후보.
2. **Google Alerts 설정**: https://www.google.com/alerts — 지문 5~9개를 큰따옴표째 알림 등록 → 신규 복제본 자동 통보.
3. **Bing/Naver**도 동일 정확검색 1회(국내 복제 대비).
4. (선택) **Copyscape** 등 표절 탐지 서비스에 `onmoment.kr/journal/<slug>` URL 제출.

복제본 발견 시 → §4.

## 4. 복제본 발견 시 대응 순서

1. **증거 보존**: 복제 페이지 전체 스크린샷 + URL + 발견일 + Wayback 저장(상대 페이지도 박제).
2. **대조표 작성**: 우리 지문 ↔ 복제본 문장 1:1 대응 캡처.
3. **권리 근거 인용**: 등록 제2026-037910호(어문저작물) + 우리 공표일(2026-06-20) + Wayback 스냅샷.
4. **조치 경로**:
   - 플랫폼 신고(네이버/티스토리/구글 등 호스트의 저작권 침해 신고 양식).
   - 구글 검색 결과 삭제: DMCA / 저작권 삭제 요청(`https://reportcontent.google.com`).
   - 직접 연락: 침해자에게 중단 요청(hello@onmoment.kr 발신).
   - 필요 시 법적 조치(법정손해배상 §125-2 — 침해 전 등록 완료로 요건 충족).
